# 2026 World Cup Match Analysis & Win Rate Prediction — Proposal by @Wailynn351

## Gist
လက်ရှိ ၂၀၂၆ ကမ္ဘာ့ဖလား (2026 FIFA World Cup) ပြိုင်ပွဲဝင် အသင်းများ၏ ပွဲစဉ်မှတ်တမ်းများကို Analysis လုပ်ပြီး Match တစ်ခုချင်းစီအတွက် နိုင်ခြေ ရာခိုင်နှုန်း (Win Rate %) ကို Machine Learning သုံး၍ တွက်ချက်ခန့်မှန်းပေးမယ့် Data Analysis Project ဖြစ်ပါတယ်။

## Story
ဘောလုံးဝါသနာရှင်များနှင့် အားကစားလေ့လာသူများသည် ပွဲစဉ်တစ်ခုမစတင်မီ မည်သည့်အသင်းက ပိုမိုသာလွန်ပြီး နိုင်ခြေရှိသည်ကို သိရှိလိုကြသည်။ ဤစနစ်သည် အသင်းများ၏ လက်ရှိ Form၊ ကစားသမားဒေတာများနှင့် သမိုင်းဝင်ပွဲစဉ်မှတ်တမ်းများကို အခြေခံကာ ပွဲစဉ်တိုင်းအတွက် ဘက်မလိုက်ဘဲ တိကျသော ခန့်မှန်းချက်များကို Dashboard တစ်ခုမှတစ်ဆင့် ထုတ်ပြပေးသွားမည် ဖြစ်သည်။

## Why
* **လက်ရှိ Trend ဖြစ်နေခြင်း:** လက်ရှိ ၂၀၂၆ ခုနှစ်မှာ ကမ္ဘာ့ဖလားပြိုင်ပွဲ ကျင်းပနေသည့်အတွက် အချိန်ကိုက်ဖြစ်ပြီး လူစိတ်ဝင်စားမှု အများဆုံးရနိုင်မည့် Project ဖြစ်ခြင်း။
* **Data Science အသုံးချမှု:** အမှန်တကယ်ရှိသော Real-world Football Data များကို အသုံးပြုပြီး Web Scraping, Data Cleaning နှင့် Predictive Modeling စွမ်းရည်များကို လက်တွေ့လေ့ကျင့်နိုင်ခြင်း။

## Why Not
* Football ဆိုသည်မှာ မရေရာမှုများ (Upsets) ရှိနိုင်သဖြင့် ဒေတာသက်သက်ဖြင့် ၁၀၀% ကွက်တိ ခန့်မှန်းရန် မဖြစ်နိုင်ခြင်း။
* ပြိုင်ပွဲကစားနေစဉ်အတွင်း ကစားသမားရုတ်တရက် ဒဏ်ရာရခြင်း (Injuries) သို့မဟုတ် ကတ်နီပြခံရခြင်းစသည့် အရေးပေါ်အခြေအနေများကို ကြိုတင်ထည့်သွင်းတွက်ချက်ရန် ခက်ခဲခြင်း။

## Tech Spec
* **Backend & Analytics:** Python (Pandas, NumPy, Scikit-learn, Beautiful Soup / Selenium)
* **Visualization/Frontend:** Streamlit သို့မဟုတ် Jupyter Notebook (Interactive Charts & Graphs များဖြင့် ပြသရန်)
* **Database/Data Storage:** CSV ဖိုင်များ သို့မဟုတ် SQLite

## Definition of Done
- [ ] ကမ္ဘာ့ဖလားပြိုင်ပွဲဝင် အသင်းများ၏ သမိုင်းဝင်ဒေတာနှင့် လက်ရှိပွဲစဉ်ဒေတာများကို Web Scraping လုပ်၍ သိမ်းဆည်းနိုင်ခြင်း။
- [ ] Match တစ်ခုချင်းစီအတွက် Win/Loss/Draw ရာခိုင်နှုန်းကို ခန့်မှန်းပေးမည့် Machine Learning Model တစ်ခု တည်ဆောက်ပြီးခြင်း။
- [ ] ပွဲစဉ်အလိုက် ဆန်းစစ်ချက်များနှင့် Prediction ရလဒ်များကို လှပစွာ ပြသပေးမည့် UI/Dashboard တစ်ခု ဖန်တီးပြီးခြင်း။
